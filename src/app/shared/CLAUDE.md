# Shared

Cross-cutting utilities, pipes, directives, and components used across the application.

## Files

| File                    | What                                    | When to read              |
| ----------------------- | --------------------------------------- | ------------------------- |
| `required-decorator.ts` | Required input decorator for validation | Input validation patterns |
| `title-helper.ts`       | Page title utilities                    | Title management          |

## Directories

| Directory     | What                                         | When to read       |
| ------------- | -------------------------------------------- | ------------------ |
| `pipes/`      | Custom Angular pipes for data transformation | Display formatting |
| `directives/` | Shared directives (tooltip, auto-resize)     | DOM manipulation   |
| `loading/`    | Loading spinner component                    | Loading states     |
